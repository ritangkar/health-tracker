# Manual checklists for the owner (A10)

Plain words, about one page. Do these on a real phone after the app is on GitHub Pages. Tick each line. Write down anything odd with the screen name.

## A. iPhone (Safari 16.4 or newer)
1. Open the Pages link in Safari. Share, Add to Home Screen. Open it from the Home Screen icon. Create the two profiles INSIDE this installed app.
2. Settings, Install and updates: it says the app is installed (or the 3 steps show in Safari).
3. Add food: tap Add food. The keyboard opens on the search box. The sheet must not jump and the search box stays visible while you type. Type "dal", tap a result, tap Add.
4. Bottom bar and Quick actions are not hidden by the home bar line at the bottom.
5. Turn on airplane mode. Close and open the app. Today still opens. Add a glass of water. Turn airplane mode off.
6. Check-in: take a photo with Camera, then one from the Photo library. Both appear, the app says "Preparing photo" and finishes.
7. Settings, Backup: Prepare backup, then Share or Save. Save to Files. Last backup date updates.
8. Press the phone's Back gesture: from a sheet it closes the sheet. From Workout it goes to Today. At Today it leaves the app.

## B. Android (Chrome)
1. Open the link. Settings, Install and updates, tap Install. Open from the icon.
2. Repeat items 3 to 8 of the iPhone list. Back button behaves the same.
3. Camera and gallery both work in the check-in.

## C. Screen reader (VoiceOver on iPhone, TalkBack on Android)
Turn it on, then:
1. Today: it reads the calories ring and the Protein, Carbs, Fat bars as sentences (for example "Calories: 1,420 of 1,900 kcal").
2. Tap Water, Steps, Sleep: the sheet opens, the reader says its name, the first field is focused. "Decrease/Increase" buttons say what they change. Save says "Saved".
3. Food add: results are read with name, serving and kcal. The small "est." chip should be read as "estimate" (known finding F-A10-05: write down what you hear).
4. Workout session: each row says exercise name, target, and the stepper says "Actual for Push-ups". After you enter 7, you hear the update.
5. Backup: the red warning box is read. Prepare, then Share, then the result message is read.
6. Trends: each chart has a text summary and a "Show table" button that works.

## D. Keyboard on a computer (Tab, Shift+Tab, Enter, Space, Esc, arrow keys)
1. Tab through Today: a visible 2 px outline is always on the focused item.
2. Open Add food with Enter. Esc closes it and focus returns to the button you used.
3. In Add food, Tab to the tab row (Recent, Frequent, Favourites, Categories) and use the Left and Right arrows.
4. Plan editor: use the Move up and Move down buttons to reorder an exercise.
5. Check-in wizard: Next moves to the next step and the page title is focused.
6. Import a backup: you can reach and press "Choose backup file" with the keyboard (known finding F-A10-04: note any extra unlabelled stop).

## E. Zoom and text size
1. Phone: set the largest system text size. Open Settings, Storage, Targets, Display, Backup, Choose workout, New check-in. Nothing should need sideways scrolling (known finding F-A10-01: expect failures until it is fixed).
2. Computer: browser zoom 200%, then 300%. Same screens, same rule.

## F. Look and feel
1. Phone Dark mode on: app is dark, no white flash when opening. Settings, Display, Theme: Light and Dark stick after closing the app.
2. In the phone accessibility settings turn on Reduce Motion. The ring and sheets then appear without animation.
3. Go over your calorie target on purpose: the text says "+N over" in normal colour, not red.

## G. Updating (release day)
1. Upload the new files, version.js LAST. Wait 2 minutes. Open the app: "Update available" banner appears. Tap Reload once. Your data is still there.
2. If it does not appear: Settings, Install and updates, Check for update. If still stuck: Repair app (this keeps your data).
3. Never choose "Clear site data" in the browser without a fresh backup first.
