Winter Arc icon maker

This page turns icons/icon.svg into the four PNG icons the app needs. The repository already ships these four files, so you only need this page if you change the icon.

  1. Open this page from your GitHub Pages address, for example https://USERNAME.github.io/REPO/tools/make-icons.html. It does not work when opened as a file from your computer.
  2. Press Make icons. Your browser downloads four files: icon-192.png, icon-512.png, icon-maskable-512.png and apple-touch-icon.png.
  3. In your GitHub repository open the icons folder, choose Add file, Upload files, drag the four files in and commit.
  4. Change WA_VERSION in version.js so phones fetch the new icons.

You can delete the tools folder once the icons are uploaded.
